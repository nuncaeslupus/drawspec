## Goal
Any diagram can come out looking like the README hero (docs/hero.png): white ink on
blueprint blue, a fine grid, a zone-marked border with registration marks, and an optional
engineering title block (title, scale, sheet, revision) filled in from the document.

## Scope
- A theme feature, not a new kind: a `[canvas]` section, e.g. `pattern = "grid"`,
  `border = "zoned"`, `title_block = true`. It only applies to the `standalone` profile
  and PNG export. The `inline` profile keeps inheriting the page.
- A bundled `blueprint` theme built on it. Reuse what tools/hero.py already draws.
- The title block takes its fields from document fields that already exist (`title`,
  `version`, the kind); there are no coordinates in the format.
- Contrast and greyscale checks still pass; there is gallery and PNG proof for a few kinds.
