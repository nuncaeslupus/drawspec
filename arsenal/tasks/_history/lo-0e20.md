## Acceptance gate

`unlabelled_axis_count == 0`

An unlabelled axis is a validation error, not a silent omission — a missing vertical axis label was one of the three worst failures in the source corpus. Point markers lie ON the series path, not beside it. Point labels cross neither the curve nor the plot edge. The vertical axis label is rotated and the horizontal one is not, consistently.
