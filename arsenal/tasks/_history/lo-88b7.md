The repository has `README.md`, `LICENSE` and a CI workflow, and none of the
files a visitor checks to judge whether a project is alive and safe to depend on:
no `CONTRIBUTING.md`, no `CHANGELOG.md`, no `SECURITY.md`, no issue or PR
templates under `.github/`.

Most of the content already exists and is only in the wrong place:

* **CONTRIBUTING** — the `Makefile` targets are the whole workflow (`make sync`,
  `lint`, `test`, `gallery`, `docs`, `schema`), and the two rules that are not
  obvious deserve saying out loud: `docs/format.md`, `docs/cli.md`,
  `docs/theme.md` and `schema/drawspec-v1.schema.json` are **generated** and a
  test fails if a hand-edit diverges; and `docs/gallery/` is committed on purpose
  so a diff shows what a change did to the pictures.
* **CHANGELOG** — shares a deliverable with **A3**; whichever runs first writes
  it and the other checks it.
* **Issue templates** — a bug template that asks for the *document* is worth more
  here than the usual form, because a drawspec bug is almost always reproducible
  from the JSON alone. Ask for the document, the theme, and `drawspec --version`.

Deliberately **not** proposing a CODE_OF_CONDUCT: for a single-author project with
no contributors yet it is boilerplate, and it can be added the day a second
person shows up.

## Acceptance gate

The files exist, and CONTRIBUTING actually names the generated artefacts — the one
thing a new contributor will otherwise get wrong on their first PR.

```bash
set -e
test -f CONTRIBUTING.md
test -f .github/ISSUE_TEMPLATE/bug_report.md || test -f .github/ISSUE_TEMPLATE/bug_report.yml
python3 - <<'PY'
import pathlib
text = pathlib.Path("CONTRIBUTING.md").read_text(encoding="utf-8")
for generated in ("make docs", "make schema", "docs/format.md", "docs/gallery"):
    assert generated in text, f"CONTRIBUTING never mentions {generated}"
print("CONTRIBUTING names the generated artefacts and how to regenerate them")
PY
```
