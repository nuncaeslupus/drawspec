**The highest-value task for "used by LLMs", and the one nothing else substitutes
for.** drawspec's whole premise is that a language model can write its documents.
Today the material that would teach one is `docs/format.md` (314 lines) and
`docs/guide.md` (473) — excellent for a human reading a page, far too large to
drop in front of an agent as a preamble, and neither is written as instructions.

An agent working in some other repository that has drawspec as a dependency needs
one file it can read whole: **what the thirteen kinds are and when each applies,
the fields each takes, the fields that are refused and why, and two or three
worked examples.** `AGENTS.md` at the repository root is the convention coding
agents already look for; an `llms.txt` pointing at it costs nothing more.

**The thing that makes this worth building rather than writing once.** A hand-kept
brief rots the first time the format moves — which is exactly the failure the
three generated references were built to prevent. So hold it to the same
standard: **every fenced JSON example in it must parse and validate against the
live schema**, asserted by a test. Then a field that changes breaks the brief in
CI rather than in somebody's agent six months later.

Prefer generating the field tables from `schema.OBJECTS` (as `tools/docs.py`
already does) over restating them, and keep the prose — when to pick `flow` over
`tree`, why there are no coordinates — hand-written. It should stay well under
200 lines; that is the constraint that makes it useful.

## Acceptance gate

`AGENTS.md` exists, names all thirteen kinds, and every JSON example in it
validates against the published schema.

```bash
set -e
test -f AGENTS.md
uv run python - <<'PY'
import json, pathlib, re
from drawspec.schema import KINDS, parse_document
text = pathlib.Path("AGENTS.md").read_text(encoding="utf-8")
missing = [k for k in KINDS if f"`{k}`" not in text]
assert not missing, f"AGENTS.md never names: {missing}"
blocks = re.findall(r"\x60\x60\x60json\n(.*?)\x60\x60\x60", text, re.DOTALL)
assert blocks, "AGENTS.md carries no JSON example, so nothing pins it to the format"
for index, block in enumerate(blocks):
    parse_document(json.loads(block))
lines = len(text.splitlines())
assert lines <= 200, f"AGENTS.md is {lines} lines; it has to fit in a preamble"
print(f"{len(blocks)} examples validate, all {len(KINDS)} kinds named, {lines} lines")
PY
```

## Tests

The gate belongs in the suite rather than only in the payload — `tests/test_docs.py`
already asserts the generated references are current and is the right home. That
is what stops the brief rotting.

## Location

`AGENTS.md` (new, repository root), `llms.txt` (new, optional, pointing at it),
`tests/test_docs.py`, and a row in the README's documentation table. Note that
`CLAUDE.md` at the root is this project's *own* development protocol and is a
different thing entirely — do not merge the two.
