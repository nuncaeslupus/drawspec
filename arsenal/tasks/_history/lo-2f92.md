Asked for directly by the owner: *add some example drawings in README.md with
their specs, so that someone who reads it can find how it is and how it works at
a glance — not the complete reference, just a first-time contact.*

**What is there now, and why it does not land.** The README carries one JSON
document (a `flow`) and, far below it, two rendered SVGs — but they are in
different sections and **the pictures are not the document**. The reader is shown
a spec, and then shown two drawings, and is left to infer the relationship. The
one thing this project has to prove in the first thirty seconds is *this input
produced that output, and nothing in between was a coordinate* — and that is
exactly the connection the current layout leaves the reader to make.

**The fix is pairing, not volume.** Two or three examples, each **spec beside its
own rendered drawing**, in the same block. Three is probably the number:

* a **`flow`** — the shape most readers came for, and the one already written;
* something visibly *not* a box-and-arrow diagram — a `timeline`, a `matrix` or a
  `quadrant` — because the thirteen kinds are the surprise, and a reader who sees
  only flow charts assumes that is all there is;
* optionally a **`chart`**, since "it draws data too" is the least expected claim.

Keep the specs **short** — trim to the fewest nodes that still read as real. A
first-contact example competing with `docs/reference/` on completeness is a worse
example. The reference documents are the full ones; these are the hook.

**Two constraints that are easy to get wrong:**

* GitHub renders `<img>` in README, and the drawings already live in
  `docs/gallery/*.svg` — use those paths rather than pasting SVG inline, so
  `make gallery` keeps the pictures current instead of the README going stale
  the first time a theme value moves.
* The specs shown must be **real documents that validate**. A hand-trimmed
  snippet that no longer parses is the exact failure `AGENTS.md` (B1) is being
  gated against, and the same gate should cover the README.

## Acceptance gate

Every JSON block in the README parses and validates, and each is paired with a
drawing in the same section.

```bash
set -e
uv run python - <<'PY'
import json, pathlib, re
from drawspec.schema import parse_document
readme = pathlib.Path("README.md").read_text(encoding="utf-8")
blocks = re.findall(r"\x60\x60\x60json\n(.*?)\x60\x60\x60", readme, re.DOTALL)
assert len(blocks) >= 2, f"only {len(blocks)} example document(s) in the README"
for block in blocks:
    parse_document(json.loads(block))
images = re.findall(r'src="(docs/gallery/[^"]+\.svg)"', readme)
assert len(images) >= len(blocks), f"{len(blocks)} specs but {len(images)} drawings"
for path in images:
    assert pathlib.Path(path).exists(), f"README points at a missing drawing: {path}"
kinds = {json.loads(b)["kind"] for b in blocks}
assert len(kinds) >= 2, f"every example is the same kind: {kinds}"
print(f"{len(blocks)} specs, {len(images)} drawings, kinds={sorted(kinds)}")
PY
```

## Tests

the same discipline the three generated pages have.
