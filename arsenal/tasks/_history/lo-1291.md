## Acceptance gate

`unrepresentable_failure_families == 11`

One test per failure family in docs/brief.md, each asserting EITHER that the schema has no field expressing it, OR that a layout invariant excludes it. The family is named in the test id. This is the acceptance suite the whole project is measured against: 63 real review notes reduced to 11 families, each made structurally impossible rather than merely checked.

```bash
uv run pytest tests/test_failure_families.py -q
```

## Tests
