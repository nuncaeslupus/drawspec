### Finding
`text` has no minimum length. A matrix cell or venn set with text "" (or " ", "\n", zero-width space) passes validation and then raises IndexError / ValueError inside the renderer - an LLM leaving a matrix cell blank gets a Python traceback (CLI) or a protocol error (MCP) instead of a located refusal.

### Evidence
Repro: matrix example with cells[0].text='' -> 'IndexError: tuple index out of range' at kinds/grid.py:918 (line.spans[0]); venn example with sets[0].text='' -> 'ValueError: max_width must be positive, got 0.0' at text/wrap.py:215. 12 fuzz cases each.

### Suggested direction
Decide per field whether blank text is legal; refuse it in validation with a pointer where it is not, and make _line_box / venn wrapping tolerate it where it is.
