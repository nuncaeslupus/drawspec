### Finding
check_embedding_safety runs its regexes over the whole SVG string, including escaped text content (quotes are not escaped in text nodes). A label such as `set href=x`, `report.ttf`, `a.woff2`, `id="main"`, `fill="red"`, `url(#grad)`, `style="x"`, or `currentColor` (standalone/PNG) makes render raise EmitError for the whole document, with no JSON pointer and a message about fonts/ids that gives an LLM nothing to correct.

### Evidence
Repro: render the `flow` example with nodes[0].text = 'open report.otf' -> 'EmitError ... no-embedded-font: references a font resource: \'.otf\''; 11 label variants tried, all refused (id=, fill=, url(#), style=, href=, .ttf, .woff2, data:font, @font-face, currentColor in standalone).

### Suggested direction
Run the checks on the element/attribute structure (or strip text nodes / escape quotes in text first) rather than on the raw string; if a label must be refused, raise a DocumentError with the label's pointer.
