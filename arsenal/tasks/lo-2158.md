The repository page is what a human — and most crawlers — see first. Three things
about it, checked against the GitHub API rather than assumed:

* **No topics at all.** `topic:` search is how "find me a diagram library" is
  actually answered on GitHub, and a repository with none is invisible to it.
  Candidates: `diagrams`, `svg`, `diagram-generator`, `llm`, `llm-tools`,
  `documentation`, `json-schema`, `python`, `dataviz`, `mermaid-alternative`.
* **No homepage set.** It should point at the gallery once **C2** publishes one,
  or at the guide until then.
* **The description is wrong about the layout engine.** It currently reads
  *"Wraps a real layout engine; writable by an LLM with no coordinates."*
  drawspec's default is its **own** `LayeredEngine` (`src/drawspec/layout/layered.py`).
  The grandalf adapter is T7's rejected candidate: it is imported lazily, sits
  behind the `spike` extra, and is deliberately not the default *because* it is
  GPLv2 / EPL-1.0 and only the EPL arm is compatible with shipping MIT code
  around it — see the module docstring of `layout/grandalf_engine.py`. So the one
  line most visitors read both misdescribes the architecture and gives away the
  licence care that went into it.

**Needs the owner or a token with repo-admin scope** — these are repository
settings, not files, and the session's GitHub app may not carry that scope. If it
does not, the deliverable is the exact list of values for the owner to paste.

While in there: `has_wiki` and `has_projects` are on and unused; an empty wiki tab
on a project asking to be taken seriously is a small tell.

## Acceptance gate

Topics set, homepage set, description corrected. Verifiable from outside:

```bash
set -e
python3 - <<'PY'
import json, urllib.request
with urllib.request.urlopen("https://api.github.com/repos/nuncaeslupus/drawspec") as r:
    repo = json.load(r)
assert len(repo.get("topics") or []) >= 5, f"topics: {repo.get('topics')}"
assert repo.get("homepage"), "no homepage set"
assert "wraps a real layout engine" not in (repo.get("description") or "").lower(), \
    "description still claims drawspec wraps someone else's layout engine"
print(f"topics={repo['topics']} homepage={repo['homepage']}")
PY
```

If the sandbox cannot reach api.github.com, run the same check through the GitHub
MCP tools and paste the result — but do not record `done` on an unverified claim.
