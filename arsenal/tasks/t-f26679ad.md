Design: `docs/proposals/text.md` (phase 1). Extend `render --format text` / `.txt`
beyond `files` to `tree`, `sequence`, `gantt`, `timeline`, `board`, `stack`, `rag` and
`meter` (progress style). Each kind lays itself out on a character grid from its layout's
topology, never from SVG coordinates.

* `render_text(document, *, width=80, charset="unicode")` in `src/drawspec/render.py`;
  CLI `--width` and `--charset unicode|ascii`; MCP `render` takes `format: "text"`.
* Over-wide drawing → refusal at the widest thing's pointer, naming the width it needs.
* Other kinds refuse, naming the kinds that have a text form.
* Roles as glyphs (table in the proposal); `files` output unchanged.
* Docs: `docs/cli.md`, `docs/guide.md`, `AGENTS.md`/`llms.txt` rows; proposal status → built.

Tests to write first, in `tests/test_text_output.py`: no line over `width` in terminal
cells (wide chars = 2); every label verbatim; ASCII charset bytes < 128; no trailing
whitespace; role pairs give different text; golden file per kind per charset; refusal
names the text kinds.
