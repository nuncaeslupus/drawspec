## What landed (PR #39)

Four pages a consumer reads, and three of them cannot go stale.

`docs/guide.md` is hand-written and is the way in: install, a first diagram,
choosing a kind, both embedding profiles, validating in a build, writing a
theme, calling it from Python, and a table of what each refusal means.

`docs/format.md`, `docs/cli.md` and `docs/theme.md` are generated by
`tools/docs.py` from the field tables, the argument parser and the theme
dataclasses — the same *one description, many renderings* principle the
published JSON Schema already runs on. `make docs` writes them;
`tests/test_docs.py` fails when what is committed is not what the code would
write.

## Four things worth carrying forward

**Generating a reference is an audit.** Filling the tables exposed 48 holes
nobody would have gone looking for: 26 document fields and 22 theme keys with no
description at all, plus 5 CLI subcommands with no `--help` description. Those
were filled at the source, so the published JSON Schema and `drawspec --help`
gained them too. A generator that renders an empty cell is telling you
something.

**Drift tests are only half of it.** Comparison catches a page that went stale;
it cannot catch a page that was never told about a new thing. So each reference
also asserts *completeness* against its own vocabulary — every kind, object and
refused field; every command and argument; every theme section, key and role —
plus that the set of theme sections the loader accepts is exactly the set the
page documents. The review found the one gap this missed (`--version`, on the
root parser rather than any subcommand), which is itself the argument for the
check.

**A description is a claim, and claims get checked.** Writing "Unique within the
document" on `group.id` was the most valuable line of this session, because it
was false. Three groups sharing two ids validated, rendered, and drew one
caption of three — `members` and `captions_for` are both dicts keyed by that id,
so a repeat replaces rather than draws. Now a located violation, across nodes
and groups both.

**The habit held for the fourth session running, from a different direction.**
Nothing was found by rendering this time, because nothing rendered differently.
It was found by *running the thing and reading the output*: `drawspec validate`
had been printing every violation twice since before this branch, and it took
looking at one refusal to see it.
