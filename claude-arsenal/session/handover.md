## Decisions taken this session — do not relitigate

**Fonts.** Bundled generics are coverage-reduced **DejaVu** subsets (~300 kB for
three files, from ~1.4 MB), regenerated by `tools/subset_fonts.py`. Subsetting
preserves advance widths and kerning; the family names are deliberately *kept*,
so the SVG names the family it measured. This settles the handover's open
question about the fallback set.

**The default theme's font stacks lead with the bundled generics**
(`["DejaVu Sans", "sans-serif"]`), not with families drawspec does not ship. A
default that always warns about a substitution trains people to ignore warnings.
A consumer theme should put *its page's* family first.

**Substitution is only reported when the metrics changed.** Falling past the
first stack entry to a different file carrying the *same* family is not a
substitution.

**Arrow heads are real primitives, not SVG `<marker>` defs.** This removes the
classic id-collision surface entirely — a titleless diagram emits no ids at all.
It puts a requirement on T9: **routing must produce head geometry**. The
emitter's contract is that an *edge-role* `Polygon` (or closed `Path`) is a head,
filled with the edge's colour and unstroked, and an *edge-role* open `Path` is
the shaft.

**`[canvas] ink`** is what `currentColor` resolves to in the `standalone`
profile. It is in `Theme.declared_colours()`, which is the emitter's allowlist.

**Node shapes** are `rect`, `pill`, `diamond`, `ellipse`, `none`; **fill
patterns** are `none`, `solid`, `hatch`, `dots`. Both closed. The emitter draws
`hatch`/`dots` as namespaced `<pattern>` defs, kept deliberately soft.

**Type scale can only be scaled as a whole** — `TypeScale.scaled(factor)` and
`Theme.with_scale(factor)`. There is deliberately no API that reaches one level.
T6's elastic fit must use these.

**The JSON Schema is generated** from the field tables in `drawspec/schema.py`,
committed once at `schema/drawspec-v1.schema.json`, and copied into the wheel
from there. `make schema` regenerates it and a test fails if the committed file
drifts. Referential checks (unique ids, edges that land) are parser-only and the
schema says so in its own description.

**Two document-contract names changed from the spec's sketch**, both because the
rejection table forbids the obvious spelling: a chart's axes are keyed
`horizontal`/`vertical` (not `x`/`y`), and a series' values are `data` (not
`points`). Update `status/specification.md` §5.1 if it is ever revised.

**`wrap` returns a `TextBlock`**, not a bare list: the height and the baselines
have to come from the same place as the lines. `block.baseline(i)` is what T6
centres with. Iterating a block yields its lines, so §5.5's `-> list[Line]` is
`list(block)`.

**Inline span parsing lives in `text/wrap.py`**, because spans change the
measurement — a wrapper blind to them measures the wrong string.
