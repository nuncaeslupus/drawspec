# B2: drawspec kinds / drawspec example <kind> — self-orientation offline

An agent that has drawspec installed but not its documentation has `--help`, which
lists four commands and says nothing about what a document looks like. `drawspec
schema` emits the JSON Schema, which is complete and is 30 000 characters — the
right artefact for an editor, the wrong one for a preamble.

Two small commands close that:

* **`drawspec kinds`** — the thirteen kinds, one line each on what each is for.
  The same sentences `docs/kinds-wanted.md` already sorts the corpus by.
* **`drawspec example <kind>`** — a valid minimal document for that kind, on
  stdout, ready to be edited. `docs/reference/` already holds one document per
  kind and they are already shipped-adjacent; the question to settle is whether
  to ship them in the wheel (as the schema is force-included) or to carry a
  smaller hand-written minimum per kind.

The pairing is the point: `drawspec example flow | drawspec validate -` should
round-trip, so an agent can confirm its toolchain works before writing anything.

## Acceptance gate

Both commands exist, `kinds` names all thirteen, and every kind's example
validates — through the CLI, not through the library.

```bash
set -e
uv run python - <<'PY'
import subprocess
from drawspec.schema import KINDS
listed = subprocess.run(["uv", "run", "drawspec", "kinds"], capture_output=True, text=True, check=True).stdout
missing = [k for k in KINDS if k not in listed]
assert not missing, f"drawspec kinds omits: {missing}"
for kind in KINDS:
    example = subprocess.run(["uv", "run", "drawspec", "example", kind],
                             capture_output=True, text=True, check=True).stdout
    check = subprocess.run(["uv", "run", "drawspec", "validate", "-"],
                           input=example, capture_output=True, text=True)
    assert check.returncode == 0, f"{kind} example does not validate: {check.stderr}"
print(f"all {len(KINDS)} kinds listed and their examples validate")
PY
```

## Tests

`tests/test_cli.py`, alongside the existing command tests. Note the gate assumes
`validate` reads `-` as stdin; if it does not, that is part of this task — an
example you cannot pipe into the validator is half a feature.

## Location

`src/drawspec/cli.py`, `docs/cli.md` (regenerate with `make docs` — it is
generated, so do not hand-edit), and whatever carries the per-kind examples.
