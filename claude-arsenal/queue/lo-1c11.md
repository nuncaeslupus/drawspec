# T0: gallery — render every reference document and look at it

## Why

Two real defects were found this session by *looking* at output, and neither was
caught by a gate:

- Two `decision` nodes drawn as 254x103 rectangles, because the spike harness
  built primitives by hand and ignored the role's shape.
- A five-node `cycle` rendered as a column of boxes with all five edges on one
  vertical line — a spec divergence (D-1) that no test asserted against.

Every gate passed in both cases. `status/specification.md` says why that is
expected: *"'correct' is mechanically checkable; 'beautiful' is not, quite."*
The plan currently schedules the first by-eye judgement at T18, which is the
close-out. That is far too late to discover a whole kind is in the wrong family.

## What to build

`tools/gallery.py`, plus a `make gallery` target.

- Render every document in `docs/reference/*.json` through `drawspec.render`,
  in both profiles, to `docs/gallery/`.
- Write `docs/gallery/index.html`: every diagram inlined on one page, each under
  its file name and kind, so the whole set is judged in one look. This doubles
  as the acceptance evidence for T17's "two fixtures in one HTML page have no id
  or selector collision".
- A kind with no renderer yet is **listed and skipped**, not an error — the
  gallery has to work while the tool is half built, or it will not get run.
- A document that raises `FitError` is listed **with its message**. The message
  is the product; seeing it in the gallery is how its quality gets judged.

## The habit this exists to support

Every kind task (D-1, T11, T13, T14) ends by running `make gallery` and looking
at the result before the gate is claimed. Note it in each payload as it is
picked up.

## Acceptance gate

The gallery builds for every reference document, and the page opens with each
implemented kind visible.

```bash
uv run pytest tests/test_gallery.py -q
uv run python tools/gallery.py --check
uv run ruff check .
uv run mypy .
```

## Tests

`test_gallery_renders_every_reference_document_it_can`.
`test_gallery_lists_an_unimplemented_kind_rather_than_failing`.
`test_gallery_page_holds_every_rendered_diagram_with_no_duplicate_ids` — the
inline promise, on a real shared page.
`test_gallery_reports_a_fiterror_with_its_message_rather_than_crashing`.
