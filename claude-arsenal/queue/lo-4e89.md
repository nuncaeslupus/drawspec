# A2: pyproject metadata — keywords, classifiers, urls, authors

`[project]` carries `name`, `version`, `description`, `readme`, `requires-python`,
`license` and `dependencies`, and stops. On PyPI that is the whole of the
discovery surface, and four of the fields that do the work are absent:

* **`keywords`** — how PyPI search finds a package nobody has heard of.
* **`classifiers`** — how the sidebar filters find it (`Topic :: Multimedia ::
  Graphics`, `Topic :: Documentation`, `Programming Language :: Python :: 3.12`,
  `Typing :: Typed`, `License :: OSI Approved :: MIT License`, and a
  `Development Status`).
* **`[project.urls]`** — Homepage, Documentation, Repository, Issues. Without it
  the PyPI page has no link back to the docs, which for this project is most of
  the value.
* **`authors`** — an unattributed package reads as abandoned before it is read.

`Typing :: Typed` should only be claimed once **A1** has landed, so this task
blocks on it in spirit — do not claim a marker that is not there.

## Acceptance gate

Every field is present, the classifiers are valid PyPI trove strings, and the
built distribution passes `twine check`.

```bash
set -e
python3 - <<'PY'
import tomllib, pathlib
p = tomllib.loads(pathlib.Path("pyproject.toml").read_text())["project"]
for field in ("keywords", "classifiers", "urls", "authors"):
    assert p.get(field), f"[project] {field} is missing or empty"
urls = {k.lower() for k in p["urls"]}
for wanted in ("homepage", "documentation", "repository", "issues"):
    assert wanted in urls, f"[project.urls] has no {wanted}: {sorted(urls)}"
if any(c.startswith("Typing ::") for c in p["classifiers"]):
    assert pathlib.Path("src/drawspec/py.typed").exists(), \
        "classifiers claim Typing :: Typed but src/drawspec/py.typed is absent"
print(f"{len(p['keywords'])} keywords, {len(p['classifiers'])} classifiers, {len(urls)} urls")
PY
uv build
uv run --with twine twine check dist/*
```
