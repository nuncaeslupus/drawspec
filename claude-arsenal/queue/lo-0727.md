# D2: repo tidy — the stray flow.svg, the home of status/, and a complete layout table

Small things, and they are the ones that make a first-time visitor decide a
project is unfinished. Each was checked rather than guessed:

* **`flow.svg` at the repository root.** A 642×663 rendered diagram sitting beside
  `pyproject.toml`. `grep` finds **no reference to it** anywhere in `README.md`,
  `docs/`, `src/`, `tools/` or `tests/` — it is a leftover from a manual render.
  Delete it, or move it into `docs/gallery/` if it is wanted.
* **`status/`.** Holds `specification.md`, `plan.md`, `spec-annotated.md` and
  `spec-reader.html` — the project's own origin documents, from before `docs/`
  existed. They are genuinely interesting (the specification is what
  `docs/brief.md` came out of) but they sit at top level next to `src/` and
  `docs/` and are named like live status. Note that `CLAUDE.md` seeds the queue
  from `status/plan.md` when the queue is empty, so **moving it is not free** —
  check that path before relocating, or update `CLAUDE.md` with it.
* **The README's repository-layout table is incomplete.** It lists `docs/*`,
  `corpus/`, `schema/` and `src/drawspec/`, and omits `tests/`, `tools/`,
  `status/`, `.claude/` and `claude-arsenal/`. A visitor scrolling the file tree
  sees five directories the README does not explain, two of which are development
  machinery they should know to ignore.

## Acceptance gate

No stray render at the root, and every top-level directory a visitor sees is
either explained by the README or deliberately excluded.

```bash
set -e
test ! -f flow.svg
python3 - <<'PY'
import pathlib
readme = pathlib.Path("README.md").read_text(encoding="utf-8")
skip = {".git", ".github", ".venv", "dist", "build"}
missing = [
    d.name for d in pathlib.Path(".").iterdir()
    if d.is_dir() and not d.name.startswith((".mypy", ".pytest", ".ruff", "__"))
    and d.name not in skip and f"`{d.name}/`" not in readme
]
assert not missing, f"README's layout table does not explain: {missing}"
print("every top-level directory is accounted for")
PY
```

## Tests

None. Deleting a stray file does not want a regression test.

## Location

`flow.svg` (delete), `status/` (decide — and check `CLAUDE.md`'s seeding path
first), `README.md` (the *Repository layout* table).
