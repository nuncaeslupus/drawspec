## Acceptance gate

`forbidden_field_acceptance_count == 0`

No field from the rejection table in specification.md section 5.1 is accepted by the parser; each raises DocumentError carrying the field's JSON pointer. additionalProperties is false throughout, so a forbidden field fails loudly rather than being silently absorbed. The committed schema/drawspec-v1.schema.json accepts and rejects exactly what the runtime validator does, so editor completion can never disagree with the tool.

```bash
uv run pytest tests/test_schema.py -q
uv run ruff check .
uv run mypy .
```
